# 后续代码模块

此目录预留以下职责，当前仅有设计说明，未实现模型或计算接口。

| 模块 | 职责 |
| --- | --- |
| structures | 构型、来源、单位与格式验证 |
| sampling | MD 候选构型生成、筛查与去重 |
| calculators | 基础模型与 DFT 结果的统一适配 |
| selection | Random、SOAP+FPS 与后续主动学习 |
| training | 微调、从头训练和检查点管理 |
| evaluation | 能量/力/应力与物理指标评估 |
| reporting | 可靠性地图、学习曲线与运行报告 |

在首次实际实现时再确定依赖与版本，避免尚未选定模型环境就固定不兼容的包组合。
