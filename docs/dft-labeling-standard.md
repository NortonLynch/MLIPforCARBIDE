## 1. 本轮采用的精度要求

同一构型、相同元素与赝势、相同电子处理方式下，将候选设置与更严格的参考设置比较，以下四项必须同时满足：

| 量 | 定义 | 允许差值 |
| --- | --- | --- |
| 每原子能量 | `abs(TOTEN_candidate - TOTEN_reference) / N` | ≤ 1 meV/atom |
| 力分量 RMS | 全部 `3N` 个笛卡尔力分量差的均方根 | ≤ 0.01 eV/Å |
| 最大力分量差 | 全部 `3N` 个分量差的绝对值最大值 | ≤ 0.03 eV/Å |
| 最大应力分量差 | 完整应力张量的独立分量差绝对值最大值 | ≤ 0.10 GPa |

这些是本项目先前选择的保守数值误差预算，不是官方通用阈值，也不是 MACE 训练误差目标。经 ZrC 文献复核，单构型绝对能量门槛不宜独自决定截断能；本轮保留原预算下的比较事实。不能仅凭单张构型在 600→800 eV 时的绝对总能量差，就认定 600 eV 在物理上不可用；需结合目标物性的相对能量、力和应力证据判断。每个代表性构型分别验收，不能用跨构型平均值掩盖失败样本。截断能和 k 网格分别满足上表，并不自动保证两项合并后也满足；最终候选还要直接对比同时提高两项的参考计算。

## 1.1 文献复核后的拟议能量校准

[01b_confirmation](../dft/jobs/01b_confirmation/README.md) 的三项补测已经返回。800/k12→800/k14 的最大应力差为 0.066531 GPa，800/k14→900/k14 为 0.055938 GPa，分别过线；但 800/k12→900/k14 联合差为 0.120301 GPa，超标。800/k10→900/k14 为 0.089452 GPa，数值上通过，不能写成 k10 数值失败；其余量也通过，但应力裕量小、变化非单调且可能存在误差抵消，因此本轮初步审核时曾保留 k14 为更保守的待验候选。当前网格选择需结合重新评估的标注目标和实际尺寸验证。

900/k14 的 `PSMAXN for non-local potential too small` 警告涉及 Zr_sv；正常结束不等于其高精度参考资格已得到确认，也不能仅凭警告宣布全部结果错误。官方要求对此类超出原设计参数范围的设置谨慎评估。[VASP 官方回复](https://vasp.at/forum/viewtopic.php?p=26126) 保留原始结果，不修改 POTCAR 来消除警告；POTCAR 设置只读，不应编辑。[VASP POTCAR 说明](https://vasp.at/wiki/POTCAR)

## 3. 正式批量标注的准入条件

1. 在具有有效参考资格的多构型校准中验证候选参数与所选 k 网格，再确定生产参数，并同步到结构优化等未运行输入；不把继续增加单张 8 原子晶胞的截断能作为唯一准入路径。现有 `02_relax`、`03_supercell_check`、`04_atomic_references` 的 600 eV 仍是原始草案，**本轮不解锁，也不应直接批量提交**。
2. 在实际标注尺寸验证 k 网格。64 原子的现有 2³/3³/4³ 测试不能由小晶胞直接代替；必要时增加 5³/6³ 或更密网格。近似等密度只能指导起点，不能替代验证。
3. 至少覆盖平衡固态、实际高温固态、最压缩/最短键、最大体积，以及确认存在的液态或缺陷等边界构型。每类先选数张不同来源的代表帧，比较生产候选与更高精度参考；失败类别要补算并重新选参数。
4. 重新抽查这些代表帧的 SIGMA、SCF 精度和最高能带占据。新增缺陷、稀疏或低配位环境需要复查自旋；本次单个完整晶胞的近零磁矩不能排除所有构型的磁性。
5. 固定最终协议及其版本号后，才生成可以进入正式训练集的标签。旧协议结果、不同数值设置的收敛试验以及合成安装测试不混入训练标签。

## 4. 每条标签的验收与数据口径

- 有完整 XML、OUTCAR 正常结束标记，电子循环真正达到 EDIFF，未耗尽 NELM；检查错误日志及 stdout/OUTCAR 警告，能量/力/应力有限。可能影响精度的警告必须评估，不能仅以 stderr 为空判作全部通过。异常帧保留原始记录，排除出训练集并单独处理。
- 实际参数、结构、元素顺序、POTCAR 校验值和版本与记录一致；静态标签的晶胞与原子位置没有改变。记录 NBANDS，检查最高能带占据足够小；当前本组为零，本项目用 ≤10⁻⁶ 作为占据诊断阈值。
- 能量统一为与力一致的 **自由能 TOTEN**，单位 eV/晶胞；另外保存 `energy without entropy` 与 `energy(sigma→0)` 供诊断。不同 SIGMA 的自由能面不同，不能混用能量口径来选取“通过”的结果。官方说明 Gaussian 展宽下力和应力与自由能一致。[VASP 展宽说明](https://vasp.at/wiki/Smearing_technique)
- 力为 eV/Å；应力采用拉伸为正、单位 eV/Å³，Voigt 顺序 `xx, yy, zz, yz, xz, xy`。原始 VASP kBar 应力转为项目应力时乘 `-0.1/160.21766208`；ASE 已完成转换的应力不再次变号。
- Gaussian `SIGMA=0.10 eV` 是固定数值展宽，不等于原子温度，也不随 4500–6000 K 改变。若研究有限电子温度，需另立协议。
- 保留输入、实际 POTCAR、来源记录、OUTCAR、OSZICAR、vasprun.xml、调度日志和优化后的 CONTCAR。收敛重复构型属于协议验证，不拆分到训练/验证/测试中制造重复样本。

首轮 11 项与本轮三项均已用 pymatgen 与 ASE 交叉核对能量、力和应力符号/单位；900/k14 的参考资格因 PSMAXN 警告另行保留为未确认。这不等于最终生产协议、正式数据导出、真实数据划分、预训练参考能量匹配和高温物理验证已经完成。
