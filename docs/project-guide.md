# 图解：项目在做什么

![项目总览](figures/project-overview-v2.png)

这是一项研究“模型的适用边界和修复成本”的实验。预训练模型已学过许多原子体系，但它是否适用于极端温度下的 ZrC、HfC、TaC，必须通过计算验证。

## 1. 模型提供快速预测，DFT 提供统一参照

给定原子种类、坐标和晶胞，MLIP 预测能量、每个原子的受力和体系应力。力可以驱动 MD，从而得到原子随时间运动的轨迹。DFT 计算成本较高，用于给选定构型提供能量、力、应力标签；它本身也需要参数收敛与一致性检查。

第一轮保持基础模型权重不变，称为“零样本评估”。让模型面对常温晶体、高温非谐固体、预熔化及目标液态构型，检查误差和物理表现随条件如何变化。结果形成可靠性地图：哪些条件满足预先设定的判据，哪些仍证据不足，哪些明显失效。

温度不是唯一变量；密度、晶胞、结构状态和采样来源也要记录。图中的绿色、黄色、红色只是概念示意，没有对应实测边界；4500–6000 K 也不能直接作为液态的判断依据。

## 2. 挑选值得付费计算的构型

MD 可产生大量相似构型，不必逐帧进行 DFT。候选池经过异常筛查和去重后，比较以下选择方式：

| 方法 | 选择依据 | 要验证的问题 |
| --- | --- | --- |
| Random | 从同一候选池随机抽取 | 简单基线能做到什么程度？ |
| SOAP + FPS | 用局域结构描述符表示构型，再挑结构差异大的样本 | 结构多样性是否提高每次标注的收益？ |
| 不确定性 / 迭代主动学习 | 用经校准的不确定性或模型分歧选择样本 | 针对困难区域补数据是否更有效？ |

前两种是 MVP 范围；主动学习属于后续扩展。不确定性方法依赖具体模型接口，不能预设所有模型都能直接提供可信的不确定性。

## 3. 用相同数据预算比较“修复”和“从头学习”

微调从已有基础模型权重出发；从头训练使用相同架构但随机初始化。两者使用同一标注集，并记录超参数、计算投入和随机种子，在独立测试集上比较。

完整研究拟考察 20、50、100、200、400 个训练构型的学习曲线。MVP 先建设 100–200 个适配构型的池，并选择可承担的较小预算开展实验；400 点不属于首轮任务。验证和测试用 DFT 构型单独计数。

固定测试集只用于报告最终表现，不能用于选构型、调参或早停。模型调试依靠训练集和验证集，主动学习只能从训练侧候选池选择新构型。

## 4. 怎样判断项目成功

- **可靠性边界**：不仅报告总体平均误差，还能定位在哪类构型和条件下不可靠。
- **数据效率**：在相同目标精度和物理判据下，比较预训练微调与从头训练所需的 DFT 构型数。若某方法未达到目标，只报告观测范围内的结果。
- **构型价值**：相同预算下比较不同选择策略，结合不同种子的波动判断收益。
- **物理可信度**：微调后的模型还要接受新 MD 轨迹检验，查看 RDF、配位数、密度、扩散和稳定性；稳定运行本身不等于预测正确。

DFT 单点可以评估能量、力、应力，但不能单独提供可靠的扩散或完整 RDF 动力学参照。物理量比较所需的 AIMD 或其他可信参考、误差与计算预算需要另行设计。
