# ZrC 首轮 MACE MD：执行范围与自动审查

> 首轮已于2026-09-24汇总为162/162数值完成，本地STOP标记保留。本文描述历史运行协议，不授权重新启动。跨本地/集群的最新状态以 [项目进度](project-status.md) 和 [统一轨迹索引](../hpc/reviews/completed-round1-20260924/trajectory-index.json) 为准；本地summary不代表全部集群结果。

本轮用户已明确授权：先完成所有组合的短测，再自动进行每组 **5 ps 平衡 + 10 ps 采样**，并自动审查结果、启动后续任务。无需逐组重复确认。机器参数见 [本轮配置](../configs/experiments/zrc_mace_round1.json)；实际运行状态以 `experiments/zrc_mace_round1/summary.json` 和各任务日志为准，本文不是完成证明。

本轮范围覆盖旧方案中尚未全面启动的组合，也把 8 原子纳入 MD 对照；以本轮配置为准。原有结构、DFT 校准记录及模型权重保持各自来源。

## 1. 全部组合与目的

| 参数 | 本轮范围 |
| --- | --- |
| 原子数 | 8、64、216；各含等量 Zr 和 C |
| 温度 | 300、1500、3000、4500、5250、6000 K |
| 体积 | 0.95、1.00、1.05 V_start |
| 初始速度/随机流种子 | 17、42、2026 |
| 组合总数 | 3 × 6 × 3 × 3 = **162** |
| 模型 | 固定本地 MACE-MH-1、`omat_pbe`、权重 SHA-256 |
| 周期边界与晶格 | 三维周期 B1 ZrC，初始 a = 4.7 Å |

V_start 来源于初始晶格，不是已优化的 DFT 平衡体积。0.95/1.05 是**体积比**，边长乘对应体积比的立方根。缺少的尺寸/体积输入从 8 原子常规晶胞构造，并记录实际晶胞和文件校验值。

本轮输出是数值可用性报告与候选构型池。64 原子构型适合后续经济地送交 DFT；216 原子用于尺寸对照。8 原子的温度涨落较大，而且运动模式和结构关联受盒子强烈限制，不能据此判断熔点或宣称体相尺寸已收敛。

## 2. 排程与阶段

1. 单 GPU 顺序运行，避免多进程同时争抢 RTX 5060 显存。每个固定 `(原子数, 体积, 种子)` 是一个加热家族，共 **27** 个家族。
2. 每个家族从 300 K 初始化速度，依次进入六个温度。高温段从同一家族前一个已通过短测的末态继续，以 **1500 K/ps** 升温，再在目标温度运行 **0.5 ps** 短测。升温段单独标记，不混入目标温度采样统计。
3. 同尺寸 3000 K、中心体积、seed=17 的短测完成后，先运行温态数值检查；通过后才启动该尺寸高于 3000 K 的短测。6000 K 对应末态就绪后运行高温数值检查。门控依据对照结果选用可接受的步长与数值精度。
4. **162 个短测全部通过，且三种尺寸的高温数值检查全部通过后**，各组合从**自身短测末态**出发，分别运行 **5 ps 平衡 + 10 ps 采样**。不能从同温度另一种子、另一体积或另一尺寸借末态冒充独立重复。
5. 短测/数值检查失败时，保留失败证据；在有限的数值重试范围内排查。重试耗尽则明确标记 `blocked_review`，继续不受阻塞影响的独立家族；全局门控未通过时不能进入生产阶段，也不放宽验收条件制造“全部通过”。

162 段目标温度短测共 81 ps。若每个家族沿完整升温路径推进，从 300 到 6000 K 的升温时间为 3.8 ps，27 家族合计 102.6 ps。正式平衡与采样合计 **2430 ps**。这些是总模拟时间，不是墙钟耗时；数值检查、重试及断点恢复另外计时。静态推理基准不能代替实际 MD 吞吐量估计。

## 3. 积分、断点与数值对照

使用 ASE Langevin NVT，摩擦系数 0.01 fs⁻¹。使用 `FixCom` 约束，并设置 Langevin `fixcm=False`，使 ASE 3.29 的自由度计数和质心处理一致。初始 Maxwell–Boltzmann 速度移除质心运动；不通过反复重新赋速掩盖异常。

允许的数值尝试依次是 `(0.5 fs, float32)`、`(0.25 fs, float32)`、`(0.25 fs, float64)`。减小步长和提高数值精度是积分排错手段，不会把模型本身的物理误差自动修复。重试从有记录的阶段起点进行；不能从失稳后的任意帧继续拼接成一段“成功”轨迹。

每 **5 fs** 记录诊断，每 **50 fs** 保存候选帧和断点。断点需包含原子位置、动量、晶胞、随机数状态、阶段、步数/时间、数值设置及模型身份。重启沿已有阶段继续；若无法保证恢复来源完整，应另立尝试记录，不覆盖旧结果。

在每种尺寸的 **3000 K、6000 K，中心体积，seed=17** 的已通过短测末态上进行：

- 同一位置、同一动量出发的 **1 ps NVE**，比较 0.5/0.25 fs。初始数值筛查线为绝对总能量漂移 ≤ 1 meV/(atom·ps)，同时记录波动与步长敏感性；此线不是 DFT 物理正确性的证明。
- 同一构型的 float32/float64 静态力、应力对照，以及相对于同盒子理想晶体参照的每原子能量差对照。原始绝对能量差也保留作诊断；记录实际差值及执行时采用的门槛。

不得在看见失败后偷偷放宽门槛。若边界情况需要额外测试，应记录原因和新增计算，保留原始失败状态与结果。

## 4. 自动审查的含义

自动审查核对模型与输入身份、预定时长、轨迹/断点完整性、有限值、异常温度和力、温度/能量/压力的时间序列、以及 NVE 和数值精度检查。温度涨落应考虑原子数与约束自由度；不能用适合 216 原子的瞬时温度阈值机械淘汰 8 原子体系。

任务的 `pilot` 和 `production` 状态与适用的 `gates` 应分别记录。正常退出、积分稳定、统计平稳、物理可信是不同结论：例如 15 ps 全部完成却仍有长期漂移，应记录为“计算完成但统计审查未通过”，不能把固定 5 ps 时长视为已平衡证明。短键或大力报警需保留原始数据，不把未经标定的任意距离当作删掉疑难构型的物理标准。

NaN/Inf、不可恢复异常或身份校验失败时停止相应轨迹，保留最后可追溯的有限值帧。失败前构型可能有助于后续 DFT 诊断，但模型预测不能改名作为 DFT 标签。

## 5. 操作入口与状态

在工作区根目录、已部署 MACE 的 base 环境运行：

```text
python scripts/run_zrc_md_campaign.py init
python scripts/run_zrc_md_campaign.py status
python scripts/run_zrc_md_campaign.py run
```

默认配置为 `configs/experiments/zrc_mace_round1.json`，默认输出为 `experiments/zrc_mace_round1`。`init` 建立清单和初始状态；`status` 读取进度与失败原因；`run` 按依赖关系执行、审查并推进后续计算，断点续跑必须复用既有输出。具体参数以执行入口的 `--help` 为准。

长期后台运行时保留控制进程日志、任务审查和心跳检查。控制进程退出不代表矩阵全部完成，监控应检查汇总状态与最近更新时间，再判断是否需要恢复。只有 162 个组合及声明的数值检查都获得明确通过结果，才能报告“全部跑通”；有阻塞则报告数量、组合及具体原因。

## 6. 数据解释边界

首轮候选池属于开发数据。来自同一加热家族、共享热态起点及其后续轨迹的数据，在未来训练/验证/测试划分时应保持来源分组。实际随机流由 SeedSequence([种子, 原子数, 体积百分数]) 派生，三体积不复用同一条随机流。未来分组仍宜保守合并同尺寸同名种子的相关体积与加热后代；调度家族键不直接等同于数据集划分键。50 fs 存帧间隔不意味着统计独立。日志记录阶段内时间和实际日期；加热家族累计时间由前驱任务和各升温/短测时长重建。检查点记录模型身份与父检查点校验值，生产段从短测分叉时保留关联。

4500–6000 K 是恒温器目标温度，不自动代表液态；部分 RDF、有序程度、按物种展开坐标 MSD 和压力统计需要联合分析。首轮“跑通”不等于确定熔点、收敛扩散系数、证明尺寸无关或认证 DFT 标注精度。后续仍需代表帧 DFT 校准、真实标签评估与针对目标物性的验证。
