## 解释边界

- 6000 K是采样上限；18帧校准DFT对照不构成可靠温度边界，边界及其扩展仍需独立评估与训练、物理验证。
- 初始a=4.7 Å和体积比例基于初始盒子，尚非DFT平衡体积。18个代表帧中MACE瞬时压力最高约44 GPa，不能直接视为常压熔化样本。
- 64原子54条轨迹中，16条在250 fs处势能相关系数绝对值大于0.2；部分轨迹有明显慢变化。抽稀和预定平衡时长不证明独立性或热平衡。
- 216原子通过连续15 ps生产计算完成；旧高温断点一致性失败证据保留，未改写为通过。
- 当前为离线几何选样；“标注—训练—重新采样—再选样”的主动学习闭环尚未实现。
