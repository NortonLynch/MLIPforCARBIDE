## 当前DFT决定

按用户最新选择固定ENCUT=600 eV，在每个64原子校准构型上比较Gamma中心6³和7³网格，共36个静态单点。使用VASP 6.3.2、PAW-PBE.64的Zr_sv/C，`cnall`分区；每任务1节点56核，默认最多4个并行。

本地当前包为`hpc/zrc-dft600-k67.tgz`；Git仅保存非赝势输入、脚本和清单。依据[任务说明](../dft/jobs/05_md_kmesh600/README.md)回传和审核，不执行旧700/800 eV扫描建议，也不重新提交已完成的GPU任务。是否已由用户在集群另行提交，需以集群记录或回传结果为准；本地没有该证据。

比较预算：相对能量差≤1 meV/atom、力分量RMS≤0.01 eV/Å、最大力分量差≤0.03 eV/Å、最大应力分量差≤0.10 GPa。7³是较密对照，两档一致不证明绝对收敛；本批也不新增截断能收敛认证。这些数值预算不是模型可靠性阈值。
