# ZrC 标注截断能：文献与本项目结果的重新评估

检索日期：2026-09-21。范围是文献的计算方法及本地收敛数据，不是逐图全文精读。

**现有证据不能证明本项目必须使用 800–900 eV。建议将 600 eV 重新列为生产候选，在有代表性的构型上用 700/800 eV 抽查。** 这不是宣布 600 eV 已对整个高温构型空间收敛，也不撤销之前计算得到的差值。先前用单张构型的绝对总能差作为硬门槛，容易使选参过于保守。

## 本地结果比“论文用了多少 eV”更有决定性

相同 POSCAR、POTCAR、k8、SIGMA=0.10 下，600 eV 相对 800 eV 的差值为：

| 指标 | 差值 | 对原先项目预算的判断 |
| --- | ---: | --- |
| 单构型绝对 TOTEN / 原子 | 1.647009 meV/atom | 高于原先 1 meV/atom 门槛 |
| 力分量 RMS | 0.0005199 eV/Å | 明显小于 0.01 |
| 最大力分量差 | 0.0013246 eV/Å | 明显小于 0.03 |
| 最大应力分量差 | 0.0476262 GPa | 小于 0.10 |

数据来源：[第一轮审核](../dft/reviews/convergence-2026-09-21.json)。这说明在该构型上，提高截断能的差异主要体现在绝对能量，力和应力已相当稳定；是否为近似恒定偏移，仍须多构型验证，不能由一个点证明。

另外，800 eV/k8→k10 的应力差为 0.2343501 GPa，明显大于上述截断能造成的应力差。k 点采样问题应单独解决，提高 ENCUT 不能代替 k 网格验证。新补测中 k10 相对 k12/k14 的四项数值均通过；k12 相对 900/k14 的应力差 0.1203015 GPa 超过旧标准，且 900/k14 有 PSMAXN 警告。这些事实均保留，不重新解释为“已通过”。见 [补测审核](../dft/reviews/confirmation-2026-09-21.json)。

## 修订选参方式，而不是为了通过测试改数字

对于固定化学计量的势函数，能量整体常数不会改变力；更相关的是不同构型之间的能量差。保持所有原始 TOTEN 标签不变，对每个校准构型 i 与预先选定的同成分参考构型 r，比较：

`δΔe_i = [E_low(i)/N_i − E_low(r)/N_r] − [E_high(i)/N_i − E_high(r)/N_r]`

若 600 和 800 eV 的差主要是与构型无关的能量偏移，δΔe 可以比单构型绝对差小得多；若偏移随体积、配位、温度或相态变化，δΔe 仍会揭示问题。不能逐帧平移能量使误差消失，也不能用测试集逐帧拟合校正。变成分、空位形成能或孤立原子参考需要一致的化学势/元素参考校准，不能直接套用单一常数。

建议保留原先的力与应力预算；把 **相对构型能量差 ≤1 meV/atom** 作为新的校准目标，绝对总能差继续记录为诊断量。这仍是项目提出的严格预算，并不是文献给出的通用验收线。新方案属于待执行的校准设计，旧审核使用的绝对能量判据和结果完整保留。

## 当前建议

1. **优先验证 600 eV**，维持 PAW-PBE.64 Zr_sv/C、PREC=Accurate、LREAL=F、LASPH=T、EDIFF=1E-7、ISMEAR=0、SIGMA=0.10。600 是候选，不是直接放行正式批量标签。
2. 在实际标注尺寸选约 10–20 张校准构型，覆盖近基态、热膨胀、压缩短键、高温固态和确认存在的液态；先用一致的足够密 k 网格对比 600/700，必要时为少量最难帧增加 800。数量是工作建议，不是文献证明的统计充分性。
3. 同时验证构型间能量差、力、完整应力、SCF 和物理警告。若 600 达标，整个正式数据集统一用 600；若关键域不达标，再统一提高到 700 或重新定义数据协议。不要把不同 ENCUT 的标签无标识混训。
4. 对 64 原子构型单独检查 k 网格。不能因 8 原子用了 k14 就给大超胞也用 k14，也不能根据他人论文直接断言 Gamma-only 或 k3 足够。
5. 已生成的 850/k14、850/k16 输入保留为**可选的严格参考检查**，不再作为当前必须追加的任务。优先把算力用于代表性构型覆盖与相对能量校准。当前没有必要因为单张结构的绝对总能量门槛，持续提高到 850–900 eV。

本次更新改变的是选参优先级和拟议的能量校准定义；没有更改任何已返回结果、赝势内容，也没有声称已完成正式高温域验证。
